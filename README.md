# Web Map Evaluation App

Tato aplikace slouží k hodnocení kvality webových mapových aplikací na základě sady definovaných kritérií.

Hodnocení je založeno na:
- kartografických a uživatelských kritériích
- jednoduchém binárním hodnocení (ano / ne / nelze zjistit)
- váhovém systému (povinná a doplňující kritéria)

Aplikace umožňuje:
- interaktivní vyplňování hodnocení
- automatické vyhodnocení výsledků
- generování přehledného reportu

## Spuštění projektu

bash
npm install
npm start

# Web Map Evaluation App

This application is designed to evaluate the quality of web map applications based on a defined set of criteria.

The evaluation is based on:
- cartographic and usability criteria
- simple binary answers (yes / no / cannot determine)
- a weighted system (required and additional criteria)

The app allows you to:
- interactively complete evaluations
- automatically calculate results
- generate a clear summary report
